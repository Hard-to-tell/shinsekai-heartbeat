# Heartbeat Companion｜心跳陪伴

让 Shinsekai 角色不必永远等你先开口，也不只会陪你闲聊。

你安静一会儿后，角色会自然地接着聊天、主动问候，或结合当前时间和屏幕内容说点什么。想专注时，只要对它说一句 **“我要学习，请监督我”**：它会安静陪你完成一轮 25 分钟学习，认真学习时不打扰，刷视频或逛娱乐内容分心时才把你叫回来——提醒多了，它真的会有点生气。

你一发消息，普通心跳就重新计时。在旧版 Qt 聊天界面中，插件还会等待整轮回复和语音播放结束；Shinsekai 2.5.1 的这一保护尚未适配，详见下方兼容说明。

![角色在浏览网页时主动说话](assets/heartbeat-in-action.png)

## 能做什么

- 在随机空闲时间后主动说话，不会机械地卡点触发。
- 在识屏、自言自语、主动提问之间按权重随机选择。
- 参考最近几条对话和空闲时长，尽量接得上当前话题。
- 避免连续重复同一种模式、固定问题或语气词。
- 一句话开启低打扰学习监督；学习或判断不清时完全静默。
- 默认每 5 分钟检查一次，明确分心才提醒，连续分心时语气逐级变严。
- 默认专注 25 分钟，到点提醒起身、喝水、看看远处，并自动结束本轮。
- 内置 15 个闲聊问题，话题覆盖近况、心情、兴趣、学习与生活。
- 可选接入 Moondream Vision；没有安装时仍可正常使用其他模式。

## 三分钟上手

要求：Shinsekai 2.1.0 或更高版本。

**2.5.1 兼容说明**：插件可以加载和保存设置，但新版停用旧 Qt 聊天回调，等待整轮回复及语音播放结束的保护尚待适配。

1. 打开 Shinsekai 的 **设置 → 插件**。
2. 在插件市场搜索 **心跳陪伴 Heartbeat Companion**，点击安装并启用。
3. 完整重启 Shinsekai。
4. 回到插件页面，打开“心跳陪伴 Heartbeat Companion”的配置。

插件不要求 Moondream，也没有额外的 Python 依赖。只想让角色偶尔主动说话，保持默认设置就能直接用。

## 一句话开启学习监督

安装并启用 Moondream Vision 后，直接在聊天里说：

> 我要学习，请监督我。

角色会确认学习模式已开启，然后开始一轮默认 25 分钟的专注：

- 每隔默认 5 分钟低频看一次当前屏幕，不会持续录像或高频截图。
- 正在看论文、写作、编程、做课程作业，或在 B 站看学习视频时保持安静。
- 学习、聊天窗口或判断不清时保持安静；只有明确看到游戏、娱乐视频或社交信息流才提醒。
- 第一次会温和提醒；反复分心后会逐渐认真、不耐烦，甚至说一点轻微气话，但不会辱骂、羞辱或威胁。
- 如果她看错了，直接说“没分心”或“你看错了”，下一次检查会跳过，提醒语气也会重新从温和开始。
- 25 分钟到时提醒休息，并自动关闭本轮监督。

想提前结束，可以说 **“停止监督”**、**“结束学习”**、**“先休息一下”** 或 **“关闭学习模式”**。普通学习聊天不会误触发，必须表达明确的开启或停止意图。

学习监督默认开启；不需要时可在插件设置的「学习监督」分组里单独关闭，不影响普通心跳陪伴。

没有安装 Moondream 时，25 分钟计时和休息提醒仍然可用，但插件不会判断屏幕是否分心。

<details>
<summary>插件市场找不到时：手动安装</summary>

1. 在本仓库点击 **Code → Download ZIP** 并解压。
2. 新建 `Shinsekai/plugins/heartbeat_companion/`，把仓库文件复制进去。
3. 确认 `plugin.py` 直接位于该目录，不要多套一层文件夹。
4. 在 `Shinsekai/data/config/plugins.yaml` 末尾追加：

```yaml
- entry: plugins.heartbeat_companion.plugin:HeartbeatCompanionPlugin
  enabled: true
```

保存后完整重启 Shinsekai。不要删除 `plugins.yaml` 中已有的其他插件。

</details>

## 怎么设置

设置页提供运行状态和交流联系方式（QQ：375449714），不会在聊天画面显示状态条或倒计时。重新打开设置刷新状态；关闭“启用心跳陪伴”可暂停，重新启用可恢复。聊天关闭或识屏长时间未返回时，旧状态会标记为暂未刷新。

开启自适应策略时，最初更偏向较短的随机间隔；连续无人回应时轻微偏向较长间隔，始终不超过你设定的最长时间，也不会自动停止陪伴。用户发言后恢复活跃倾向。关闭自适应策略则保持范围内均匀随机。

普通心跳等待至少 30 秒；旧配置中不足 30 秒的值会自动按 30 秒处理。默认仍为 5～15 分钟。此限制降低打断风险，但不等于已接通语音结束通知。

设置页里最常用的是这些：

| 设置 | 怎么填 |
| --- | --- |
| 最短 / 最长空闲时间 | 每轮会在两者之间随机等待；日常可先用 `5–15` 分钟 |
| 自适应空闲策略 | 开启后，短空闲更偏向延续对话，长空闲更偏向识屏和固定问题；关闭后严格使用下方基础权重和概率 |
| 三种模式权重 | 数字代表基础相对概率；某项填 `0` 就会关闭该模式 |
| 回复句数 | 控制每次大约说几句，建议 `1–4` |
| 启用学习监督 | 默认开启；关闭后学习口令不会启动监督计时，普通心跳仍可使用 |
| 学习检查间隔 | 学习模式多久看一次屏幕，默认 `5` 分钟；数值越小，识屏开销越高 |
| 每轮专注时长 | 默认 `25` 分钟，到点提醒休息并自动结束 |
| 学习安全词 | 每行一个宽松判断提示；默认只有 `chat`，覆盖常见 AI 聊天窗口 |
| 固定问题 | 每行一个问题，触发时随机抽取一条 |
| 常用语气词 / 动作 | 每行一条，例如 `唔……`、`（打哈欠）`、`😊` |
| 提示词 | 整个输入框是一条完整指令，可直接写中文；换行不会变成多条随机提示词 |

想快速确认插件是否工作，可临时把空闲时间改为 `0.5–1` 分钟（30～60 秒）。测试结束后再改回正常时间。

配置保存后通常立即生效，不需要重启。更新插件代码或版本后才需要重启。

<details>
<summary>我想直接修改 config.json</summary>

配置文件位于：

```text
Shinsekai/data/plugins/io.github.hard_to_tell.heartbeat_companion/config.json
```

例如，只保留自言自语和提问：

```json
"mode_weights": {
  "screen": 0,
  "monologue": 50,
  "question": 50
}
```

文字要放在英文双引号中，项目之间使用英文逗号，最后一项后面不要加逗号。JSON 暂时写错时，插件会继续使用上一份有效配置。

</details>

## 可选识屏

安装并启用 [Shinsekai Moondream Vision](https://github.com/RachelForster/Shinsekai-Moondream-Vision) 后，普通识屏模式和学习监督会调用它的 `moondream_query_screen` 工具。普通识屏不可用或失败时，本次心跳会自动改成自言自语或提问；学习模式会保持静默，避免因为看不清屏幕而误批评你。

建议关闭 Moondream 自带的自动监屏触发，只保留识屏工具，避免两个插件同时主动说话。Heartbeat Companion 不保存截图或识屏摘要；所有判断都通过本机已安装的 Moondream 工具完成。

## 没有触发？

- 确认插件已启用，并在安装或更新后完整重启过 Shinsekai。
- 测试时把空闲时间设为 `0.5–1` 分钟（30～60 秒），并保持聊天窗口开启。
- 用户刚发送消息、角色正在回复或 TTS 正在播放时，计时会重新开始。
- 只关闭识屏模式不会影响自言自语和提问模式。
